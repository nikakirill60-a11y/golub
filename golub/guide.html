🕊 Голубь

Мессенджер на Python для Android. Работает через Supabase — своего сервера нет, поэтому «свет отключили» ему не страшно.

Python + Kivy Supabase только мои аккаунты очередь на диске без потерь

Что уже сделано

Проект Supabase uuokiexpadllowhzbhen уже вшит в приложение, а твой публичный ключ sb_publishable_… прописан в настройках. Осталось четыре шага — и можно переписываться.

Проверено вживую: проект отвечает, ключ принимается (вход отвечает «неверные данные» — значит связь есть). Не хватает только таблиц в базе.

Шаг 1. Создать таблицы (5 минут)

  1. Открой панель Supabase → свой проект.
  2. Слева SQL Editor → New query.
  3. Вставь весь текст файла supabase/schema.sql из папки проекта.
  4. Нажми Run. Должно появиться «Success».

Скрипт создаёт таблицы профилей, сообщений и отметок «прочитано», правила доступа (каждый видит только свои переписки) и триггер, который сам заводит профиль новому пользователю. Запускать повторно безопасно.

Шаг 2. Закрыть регистрацию ⚠️

Authentication → Sign In / Providers → Email → выключи «Allow new users to sign up» → Save.

Это и есть «аккаунты создаю только я»: без этого пункта любой, у кого есть публичный ключ, мог бы завести себе вход через API.

Шаг 3. Создать аккаунты

Вариант А — скриптом (удобно). Возьми секретный ключ: панель → Settings → API Keys → Secret keys → скопируй sb_secret_…. Затем на своём компьютере в папке проекта:

export SUPABASE_SECRET_KEY=sb_secret_твой_ключ

python3 admin.py check
python3 admin.py add петя --name "Петя"
python3 admin.py add настя --name "Настя"
python3 admin.py list

Пароль скрипт спрашивает отдельно и не показывает при вводе. Секретный ключ нужен только этому скрипту — в приложение и на GitHub он не попадает. Ещё команды: passwd имя — сменить пароль, remove имя — удалить.

Вариант Б — руками в панели. Authentication → Users → Add user → Create new user: почта вида петя@golub.local, пароль, галочка Auto Confirm User. Имя для входа в приложении — часть почты до собачки.

Шаг 4. Собрать APK и войти

  1. Выложи папку golub в репозиторий на GitHub.
  2. Вкладка Actions → «Собрать APK «Голубь»» → Run workflow.
  3. Через 25–40 минут: Artifacts → golub-apk — скачай архив, внутри golub-1.0.0-arm64-v8a-debug.apk.
  4. Скинь APK на телефон, открой, разреши установку. Иконка «Голубь» готова.
  5. В приложении введи имя и пароль — и пиши. Второй телефон — второе имя.

Как проверить, что плохой интернет переживается

  1. Включи авиарежим и напиши сообщение — оно появится с пометкой «в очереди».
  2. Закрой приложение, можешь перезагрузить телефон.
  3. Включи интернет, открой «Голубя» — сообщение уйдёт само, собеседник его получит.

Если что-то не так

СимптомЧто делать
«в базе нет таблиц — выполни supabase/schema.sql» Не выполнен шаг 1: открой SQL Editor и запусти schema.sql
«Неверное имя или пароль» Аккаунт создаёт только владелец. Проверь python3 admin.py list. Имя входа — это часть почты до @
«Ключ не подошёл» В настройках подключения нужен публичный ключ (sb_publishable_…), не секретный
«Нет сети», хотя интернет есть Проверь адрес проекта и что проект не на паузе (бесплатные засыпают после недели простоя — нажми Restore в панели)
Уведомления с задержкой Настройки → Приложения → Голубь → Батарея → «Без ограничений»

Что внутри

  • client/supabase_core.py — очередь на диске, повторы, докачка пропущенного, защита от дублей, вход и авто-продление сессии.
  • client/main.py — интерфейс на Kivy, русский, тёмная тема.
  • supabase/schema.sql — база и правила доступа.
  • admin.py — аккаунты: создать, сменить пароль, удалить.
  • tests/ — 18 автотестов, включая обрывы связи и перезапуск приложения; tools/ui_smoke.py — автотест интерфейса.

Своего сервера больше нет: приложение общается с Supabase напрямую, поэтому «свет отключили» ему не страшно. Подробности — в README.md.
