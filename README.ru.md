# Blitz Legacy: Remastered Deluxe Edition

[English](README.md) | [Русский](README.ru.md)

Танковая игра с приоритетом Android — порт **Blitz Legacy (Godot)** на Unity.
В проект входят 3D-ангар, исследование и оснащение техники, бои с ботами,
онлайн и управление с сенсорного экрана либо клавиатуры и мыши. Сцены и интерфейс
создаются на C#; конвертированные игровые данные, модели, текстуры и звук
включены в репозиторий через Git и Git LFS.

**Статус:** альфа; игровые механики, онлайн и совместимость модов продолжают
развиваться. Версия релиза задаётся в
[`BlitzVersion.cs`](Assets/Blitz/Core/BlitzVersion.cs), а не в этом документе.

## Возможности игры

- Ангар, выбор техники, деревья исследования, оборудование, снаряжение и прогресс аккаунта.
- Движение танка, прицеливание, стрельба, пробитие брони, повреждения и результаты боя.
- Карты и особые режимы, включая «Возрождение», «Большого босса» и «Войну уток».
- Локальные бои с ботами; онлайн через выделенный сервер или Photon Fusion.
- Русская и английская локализации, настройка управления, графики и звука.
- Менеджер модов и офлайн-конвертер поддерживаемых танковых `.modpack` из
  Panzer War. У конвертации есть ограничения совместимости:
  [`Tools/modpack/README.md`](Tools/modpack/README.md).

## Как играть

Используйте APK или desktop-сборку, подготовленную релизным скриптом. Готовые
сборки в Git не хранятся; этот репозиторий не задаёт публичный адрес скачивания.
На Android установите APK, на ПК распакуйте **весь** архив с игрой,
а не только исполняемый файл.

1. Запустите игру и создайте либо выберите локальный аккаунт.
2. Выберите танк и его оснащение в ангаре.
3. Выберите режим и войдите в бой. Для онлайна нужны доступный сервис и одинаковые
   версии игры; клонирование исходников само по себе не предоставляет сервер.
4. Настройте язык, графику, звук и управление в настройках.

### Стандартное управление на ПК

| Действие | Клавиша |
| --- | --- |
| Движение | W / A / S / D |
| Выстрел / удержание башни | Левая / правая кнопка мыши |
| Снайперский режим | Левый Shift |
| Перезарядка магазина | C |
| Приближение | Колесо мыши |
| Снаряды | 1 / 2 / 3 |
| Снаряжение | 4 / 5 / 6 |
| Способность режима | 7 |
| Список команд / меню / полный экран | Tab / Esc / F11 |

Назначения клавиш меняются в настройках. На Android используются экранные кнопки.

## Быстрый старт из исходников

Установите **Git LFS** до клонирования и Unity **7000.0.0a8** с нужными
платформенными модулями и действующей лицензией редактора. Точная ревизия:
[`ProjectSettings/ProjectVersion.txt`](ProjectSettings/ProjectVersion.txt).

```sh
git lfs install
git clone <repository-url> blitz-legacy-unity
cd blitz-legacy-unity
git lfs pull
git lfs fsck
python3 Tools/bootstrap_sentry_sdk.py
Tools/unity.sh import
Tools/unity.sh compile
Tools/unity.sh test
```

Команды выше рассчитаны на Linux; для Windows используйте
`py -3 Tools/unity.py <команда>`. Для онлайна и подписи скопируйте
`.env.example` в исключённый из Git `.env`. Полные требования, подписанная Android-сборка,
Linux/Windows, внешние сервисы, диагностика и различия development/productiondebug
описаны в **[BUILD.ru.md](BUILD.ru.md)**.

Исходный Godot-проект и архивы оригинального клиента **не нужны для обычной
сборки**: готовые конвертированные ассеты уже находятся в Git. Эти источники
требуются только для повторного запуска соответствующих инструментов переноса.

## Что хранится в Git

Все входные файлы сборки и их Unity `.meta` должны находиться под контролем
версий. Бинарные ассеты хранятся в Git LFS; архив с одними LFS-указателями
не является готовой рабочей копией. Кэши Unity, APK/плееры, логи, локальные
виртуальные окружения, генерируемые настройки телеметрии, секреты и ключи подписи
намеренно исключены.

Sentry Unity SDK **4.10.3** не хранится в Git: `Tools/bootstrap_sentry_sdk.py`
устанавливает его из архива с проверкой контрольной суммы. Photon Fusion и
Obfuz **уже включены**. Повторно импортировать локальный `.unitypackage` не нужно.
